Board

Dithering is the smooth dimming. It is not saved — it comes back on after a restart. The fade curve is how Pulse Modes 1 and 2 dim: 1.0 takes the same amount of light away every moment (as before v28), which the eye sees speeding up near the bottom; 2.5 is about even to the eye; 3.0 follows CIE lightness. The running front is how the running modes move: sharp switches each LED at once (as before v30); soft glides an edge 1, 2 or 3 LEDs long along the shape, each sweep taking exactly its eval time. A new front comes in with each shape’s next cycle. Both are kept.
 
Every key sends the same code as the matching button on the IR remote — except the Wave key and Pause, Play and Demo, which the remote does not have.

Relay settings

The same broker, user and topic as on the board’s WiFi setup page. Kept only in this browser, on this phone.

Use a separate broker user for the phone if you like; it only needs to publish to topic/cmd and subscribe to topic/state and topic/online — and, for the Boards list, to +/state and +/online, and to publish to +/cmd to run boards together.

Several boards: each has its own topic. The Boards button at the top lists every board on this broker; a tap switches to it. A board can also be opened directly with ?topic= and its topic at the end of this page’s address — one home-screen icon per board, if you like.

Boards

Tap a board to control it on this page. Tick boards to pause, play or run them in step together.

Together

Not connected just now

Run in step makes the ticked boards one group: every cycle starts on all of them at the same moment, once the longest is over. Pause and Play act on the ticked boards and the rest of their groups. The boards keep time among themselves over their own WiFi, so the boards of a group must be on the same network; the relay only takes the command to one of them.

A board missing? Its relay is not set up yet. At home, on the same WiFi as the boards: open that board’s own page (type its address, http://192.168.…, in the browser — or press Boards on any board’s page and open it from the list), press WiFi settings in its Board card, and fill in the card Remote access: the same broker, user name and password as the other boards, and a topic of its own. Then Save and connect the relay.
